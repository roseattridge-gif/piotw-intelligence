# Evidence Engine 0.3.1 before/after diagnostics

The same six documents and unchanged AI-assisted annotations were rerun. These figures are diagnostic agreement only.

| Metric | Before | After |
|---|---:|---:|
| PIOTW missed AI events | 14 | 0 |
| Likely false positives | 21 | 0 |
| Duplicate events | 2 | 0 |
| Severe event disagreements | 12 | 0 |
| Severe numerical disagreements | 2 | 0 |
| Semantic numerical agreement | 11 | 13 |

All predeclared development targets were met. This result is expected to be optimistic because the set directly informed engineering. It does not change the independent-human readiness gate.

The fresh development-safe check used three companies and five documents (AMD, Caterpillar and Deere). It produced 165 candidates, 61 accepted events, 64 rejected candidates, 27 ambiguous candidates and 13 deduplication links. Focused inspection classified 37 accepted events as supported, 19 as obvious false positives and 5 as ambiguous. The main observed residual issue is current-versus-historical interpretation in restructuring-cost tables and malformed table fragments. This honest fresh-sample result means the hardened extractor is technically improved but still needs human review.
