# Evidence Engine 0.3.5 Development Design

Status: separate development namespace. Evidence Engine 0.3.4 remains preserved and unchanged.

0.3.5 inserts an explicit evidence-sufficiency contract before acceptance: subject, predicate/action, actuality, timing, target relevance and event-definition fit. It adds general handling for hypothetical risks, third-party/industry subjects, legal/accounting definitions, heading-only evidence, incomplete fragments and polarity. Source-zone classification is advisory context, never an automatic decision by section alone.

The existing 0.3.4 evidence-pointer mapping and fail-closed resolution are reused unchanged. The 0.3.5 prompt is separately versioned. Pricing pressure and backlog direction are admitted as development concepts only where the evidence states the direction; backlog change is not automatically interpreted as demand causality.

All 0.3.4 failures, prior benchmarks and inspected sets are registered as `DEVELOPMENT_CONTAMINATED — NOT VALIDATION`. No issuer-specific exception is permitted.
