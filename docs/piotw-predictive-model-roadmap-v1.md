# PIOTW Predictive Model Roadmap v1

No model is trained in this phase.

## Future comparison

- Baseline A: conventional point-in-time financial and issuer features.
- Model B: outside-in operational features only.
- Model C: combined evidence model.

The research question is whether Model B adds incremental, stable, calibrated value beyond Baseline A.

## Candidate events

Restructuring/cost action; capacity expansion or contraction; leadership/operating-model change; supply disruption; quality/remediation action; major transformation intervention.

## Protocol

Freeze event labels and 6/12/18-month horizons; register predictions before outcomes; enforce `information_available_at`; preserve entity scope; compare Brier score and calibration first, ROC/PR and lift where appropriate; report lead time and stability; keep a genuinely untouched holdout.
