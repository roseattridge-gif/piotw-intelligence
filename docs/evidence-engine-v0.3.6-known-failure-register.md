# Evidence Engine 0.3.6 known-failure register

Status: development-contaminated diagnostic material, not validation and not formal gold.

The register covers all 20 known failures produced by the pre-hardening 0.3.6 family contracts on the preserved 150-case diagnostic set: five false accepts and 15 missed supported events. The row-level source spans, before/after decisions, root causes, proposed general fixes, ownership of the fix and overfitting risk are in `data/derived/evidence_engine_v0_3_6_known_failure_register.csv`.

## Failure classes and treatment

| Failure class | Before | General treatment | After |
|---|---:|---|---:|
| Hypothetical risk accepted as workforce condition | 1 | Shared actuality rule rejects conditional/failure-to language without realised impact | 0 |
| Historical supply condition accepted as current | 2 | Shared temporal rule rejects past-only conditions without a current anchor | 0 |
| Backlog metric description accepted as growth | 1 | Demand contract requires observed movement | 0 |
| Historical demand weakness accepted despite current opposite movement | 1 | Shared temporal rule rejects past-only evidence | 0 |
| Continuing transformation execution missed | 2 | Change contract recognises continuing multi-year execution with deployed action | 0 |
| Realised/persistent supply condition missed | 5 | Supply contract recognises issuer impact, mitigation and persistence | 0 |
| Indirect/current site closure missed | 2 | Delivery contract recognises closures tied to current charges/actions | 0 |
| Active restructuring plan/accrual evidence missed | 4 | Cost contract separates current plan evidence from definitions/provisions alone | 0 |
| Indirect implemented restructuring action missed | 2 | Cost contract recognises implemented structural action | 0 |
| Implemented workforce reduction missed | 1 | Workforce contract recognises initiated/ongoing reductions | 0 |

All 20 cases now produce their diagnostic expected classification. That result is regression closure only. It does not estimate unseen precision or prove the diagnostic annotations correct.

## Remaining risks

- Some active-plan evidence is expressed in accounting notes; the contract accepts only dated current-plan balances, payment or action evidence and keeps definitions/provisions alone ambiguous or rejected.
- The contaminated set is concentrated in a small number of issuers and document styles.
- Generalisation can now only be assessed with the preregistered fresh gate.
