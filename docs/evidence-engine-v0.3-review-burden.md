# Evidence Engine 0.3 - review burden protocol

Thirty reports are split evenly between human-first and PIOTW-first workflows. Each session records start/end timestamps, extracted facts, accepts, corrections, rejections, omissions added, severe corrections, and notes. The comparison reports median time per report and observation, acceptance/correction/rejection/omission rates, and percentage time saved.

Correction categories are wrong metric, value, period, unit/scale/currency, accounting basis, duplicate, language context, taxonomy, and missing observation. Timings are currently blank because no human review has occurred; they must not be inferred from parser runtime.
