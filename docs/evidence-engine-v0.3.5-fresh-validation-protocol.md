# Evidence Engine 0.3.5 Fresh Validation Protocol

The frozen machine-readable protocol is `config/evidence/semantic_fresh_validation_protocol_v0_3_5.yaml`.

It requires 5–8 genuinely unused companies and 10–16 unused difficult documents, selected without outcomes and absent from every 0.3.x URL/hash/corpus registry. All candidates, source hashes and source-first inspection labels must be frozen before semantic execution.

The one-run gate requires precision ≥95%, supported-event retention ≥90%, zero severe false positives, zero attribution errors and 100% provenance. The run stops after one result. No post-result tuning or second gate is allowed in this task.

No fresh set is yet frozen merely by this protocol. Development-contaminated cases cannot satisfy it.
